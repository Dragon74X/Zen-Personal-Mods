# Simplicity audit and review — 9 October 2026

A repo-wide "less code" audit (ponytail-audit), then a bug review of its
changes in the same spirit. This file records what was found, what was done,
what was decided against, and why. Earlier records:
[AUDIT-2026-09-18.md](AUDIT-2026-09-18.md), [REVISIT.md](REVISIT.md),
[SHELVED.md](SHELVED.md).

Releases: Glassflow 3.67.1, Groupflow 1.70.1, Iconflow 1.18.1,
Mediaflow 2.6.1 (and the `zenslop/` forwarder, which mirrors Mediaflow).

## Audit findings

| # | Finding | Outcome |
|---|---|---|
| 1 | Remove Tab Router and Tab Unloader (both off by default). | **Rejected.** Both are in constant use. The audit assumed from the defaults. |
| 2 | Build Groupflow's 35 pre-drawn rail shapes (3 line shapes × 5 curve weights) in the script instead of the CSS. | **Dropped.** The shapes are pre-computed offset outlines; building them at runtime is more code, not less. |
| 3 | Groupflow's neon marker variant was declared inside every marker style. | **Done.** See below. |
| 4 | One-time settings migrations that have already run. | **Done**, with one fallback put back after review. See below. |
| 5 | Mediaflow's PiP-window watcher: it waited for a PiP window, then only unregistered itself. | **Removed**, with what fed it: the window `deactivate` handler, `getActiveActor`, `lastPipOpenAt`, and `CONFIG.PIP_OPEN_DEBOUNCE_MS` / `PIP_OBSERVE_TIMEOUT_MS`. |
| 6 | Delete the 18 September audit and the empty `SHELVED.md`. | **Kept as records.** The audit got a status line; `SHELVED.md` was restored from `57be003` with a status note. |
| 7 | `REVISIT.md` and `glassflow/README.md` described a snapshot sampler that no longer exists. | **Updated.** The REVISIT entry is marked settled, with the commits that settled it; the README line no longer mentions it. |
| 8 | Mediaflow's `CONFIG.MAX_HEIGHT` was never read. | **Removed.** |

The 10 identical Sine update guards, the `zenslop/` forwarder and the
per-mod settings boilerplate were checked and kept: Sine stages every update
through one shared folder, old installs may still carry the `zz-zenslop` id,
and Sine mods cannot share files.

### 3. Groupflow markers

`groupflow/userChrome.css` had one block per marker style (22 tab styles,
23 subfolder styles), each repeating the tab and subfolder selectors and a
neon copy. Now each style only names its shape, in two variables, and one
shared set of rules draws whichever is chosen, picking the neon form when
**Gradient** is set to neon. 358 lines became 78.

Checked in headless Zen 1.23b: the computed marker for every combination of
tab marker (0–22), subfolder marker (0–23) and gradient (off, neon, other),
1,656 in all, is identical before and after.

## Review findings

| # | Finding | Resolution |
|---|---|---|
| 1 | Changed mods had no version or `updatedAt` bump, so Sine would not offer them. | Bumped (releases above), with Mediaflow's `@version` and the `zenslop/` copy. |
| 2 | Removing the Zenslop carry-over: a Zenslop-fork install that updates now starts from Mediaflow's defaults. | **Accepted.** The fork became Mediaflow on 4 October 2026 and the user's install carried over then. `mediaflow/README.md` now says so. |
| 3 | Captions briefly were a checkbox. A profile holding that old `false` would now get "Follow YouTube" instead of off. | **Fixed.** The two-line fallback stays: a stored `false` still means off. It reads the old value but never moves it. |
| 4 | READMEs linked to this file before it existed. | This file. |
| 5 | A profile that skipped Iconflow 1.3–1.18 may still hold `zzicon.set` 1 or 3, or a `zzicon.button.*` 2 or 3, which now match no style, so Iconflow draws nothing there and the icons stay Zen's. | **Accepted.** Picking the set again fixes it. |
| 6 | Without the 1.63.0 step, a profile still on the old default keeps "Where you are" for the folder light. | **Accepted.** It is still a valid choice, and the user's profile already moved. |
| 7 | The markers the migrations set stay in old profiles: `zzglass-migrated.*`, `zzicon-migrated.1-7`, `zzgroup.folder-defaults-v1`, `zzgroup.glow-follows-v2`. | **Left.** Nothing reads them; clearing them would be code that runs on every startup. Reset them in `about:config` if wanted. |
| 8 | `SHELVED.md` said its caches are "cleared on load now"; that code went in `6f4ea93`. | The status note at the top now says so. The body is unchanged, as a record. |
| 9 | Groupflow's `seedDefaults` counted writes only to answer yes or no. | Now a boolean. |
