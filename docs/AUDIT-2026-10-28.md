# Icon and Mediaflow hover regressions — 28 October 2026

Baseline: main `4b7312a`, Iconflow 1.21.3, Glassflow 3.74.5, Mediaflow 2.8.0;
Zen 1.23.4b / Gecko 158.0.1. The supplied chrome archive contains those same
production files, Arc 2.0, Context Menu Icons and Sidebar Expand on Hover. It
does not contain the live browser preferences or runtime state. Personal archive
contents are not included in this repository.

## Confirmed causes and corrections

| Finding | Correction |
| --- | --- |
| The native Morph restoration (`ac7e792`) limited image transitions to opacity/filter. Existing press transforms changed instantly. | Restore the existing spring transform transition on the image. Keep browser-managed vector-strip windup and native hit targets. |
| Arc scales/bounces workspace buttons while Glassflow scales their child icons. These transforms compose, and Arc's bottom origin moves the target. | Under Glassflow's existing workspace enable gate, keep the parent stationary and use the child's existing spring for hover and press. |
| Gecko's menu renderer now creates an HTML `.menu-icon` lazily. Morph searched for the older XUL slot, adding a pseudo icon and an iconic class that can suppress Context Menu Icons' background. | Render and use the native image slot; retain its source. Remove only the class Morph added on teardown. Menu animation Off remains a complete opt-out. |
| Mediaflow's positioning path referenced `now` after its declaration was removed. Native logs reproduced repeated ReferenceErrors, despite the old controls test passing. | Use `performance.now()` at the update; remove unused geometry return values and destructuring. Fail the native test on runtime errors. |
| The transparent controls layer covered the full preview and cancelled hover growth on entry. Growing geometry could also move controls under a stationary pointer. | Hit-test only actual buttons/range. Hold geometry on real pointer movement/press or focus, not synthetic boundary entry. Resume pending growth when leaving controls for the canvas. |
| Preview/caption visibility omitted the sidebar's existing `seen` gate. A focused preview could remain after the sidebar disappeared. | Reuse `seen`; clear the growth timer and interaction/focus state when hidden. |
| Unchanged volume attributes and clock text repeatedly woke Morph's observer. | Skip unchanged volume, labels, disabled state and clock text. A 60-update test now produces one volume write. This is a write-count result, not an FPS claim. |

No new settings, dependencies, production polling, wrappers or SVG overlays.
Window close/minimize/maximize/restore artwork and behavior remain excluded.
Saved preferences, the earlier tab-icon clipping correction, tab/folder spacing
work, pointer-lighting opt-in and transparent-page blur correction are retained.
