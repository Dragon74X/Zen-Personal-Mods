# Zen 1.23.3b compatibility and clean icons

Baseline: `a8105d7131e307f8ea5471bd7585e6148f20d5b6` (Iconflow 1.18.4).
Rollback branch: `rollback/pre-zen-1233-clean-icons-20261017`.

## Releases

- Iconflow 1.19.0: **Icon set → Circuit: clean** adds 59 matching icons and the alternate reload. Same geometry, sizing, spring timing, states and actions; restrained Library-style fills, no sheen, halo or hover glow. The original remains selectable and existing per-button choices remain authoritative. Clean SVGs total 4.1 MB; assets load only when selected. No extra animation loop.
- Iconflow rendering repair: static SVGs resolve through Sine's `chrome://` mapping. Generated native strips use temporary files exposed through `resource://`, allowing Gecko's default contextual SVG paint without changing the content security preference. Retirement removes those files and mappings. The strip's outer aspect ratio no longer clips non-square icon boxes. Circuit clears competing theme masks; native mask artwork retains whole-icon motion.
- Glassflow Library 1.2.6: extra rows follow the native session download list and delegate speed labels and retry to Zen's helpers. Cancel and Show in Folder match the native widget; blocked downloads retain native confirmation.
- Glassflow 3.69.2: when Glassflow owns the compact sidebar, its native blur-off/reduced-transparency choice also overrides Arc's legacy acrylic rule.

## Upstream check

[Zen 1.23.3b](https://github.com/zen-browser/desktop/releases/tag/1.23.3b) uses Firefox 158.0. Its Library API changes require the row updates above. Routing continues through the native matcher. Folder creation fixes and the compact-layout event change require no production change here. This release adds no new blur API requiring a replacement of Glassflow's existing native integration.

The broken icon paint came from file/data SVGs losing contextual theme colors. Firefox's [SVGContextPaint implementation](https://github.com/mozilla-firefox/firefox/blob/main/layout/svg/SVGContextPaint.cpp) permits those colors on trusted chrome/resource image URLs. No global SVG preference is weakened.

## Validation

Local checks only; no GitHub Actions:

```
SINE_MANAGER_SOURCE=../upstream/Sine/src/core/manager.sys.mjs node --test tools/*.test.mjs
python tools/zen-smoke.py --zen /path/to/zen-1.23.3b/zen
python tools/zen-smoke.py --zen /path/to/zen-1.23.3b/zen --arc /path/to/Arc-2.0
```

159 tests passed. Both runtime configurations passed 72 contextual icon paint cases (native/neon/clean, three dimensions, first/last frame), 21 actual download pop-out selections, Library extra-row ordering/retry/accessibility, media keyboard interaction, and the existing blur/modal checks. Clean/Neon were also visually compared in the actual browser. GPU compositor performance on the user's machine is not measured by this headless check.

## Revert

For the previous appearance, select **Circuit: glass and neon**; no reinstall needed.
For the complete previous release, restore the three mod directories from the rollback branch, then give their manifests new version numbers and current, strictly newer `updatedAt` values before publishing to `main`. An old timestamp alone will not trigger Sine's updater. The rollback branch is a complete source checkpoint; user preferences and browsing data are not migrated by this release.
