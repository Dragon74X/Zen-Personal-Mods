# Zen 1.23.4b compatibility check

Checked repository baseline `9fe8d0d` against [Zen 1.23.4b](https://github.com/zen-browser/desktop/releases/tag/1.23.4b), published October 21, 2026, using Firefox 158.0.1. Upstream source: `541ee55196395ee8082862b83c84c90ab41d9f6d`; compared with 1.23.3b. All 10 current mods were included in source review.

## Result

The initial compatibility pass found no mandatory API repair. The feature-adoption pass adds Glassflow 3.70.0 and Mediaflow 2.6.3 below; their Sine timestamps advance. Other mod releases remain unchanged.

| Changed upstream flow | Mod compatibility |
|---|---|
| Media controller moved to a system module | Mediaflow uses the retained per-window `gZenMediaController.onAudioPlaybackStarted` method. Runtime checks confirm its window and toolbar bindings. |
| Folder completion event changed to `TabGroupAnimationComplete` | Groupflow does not subscribe to the removed event. Collapse, loaded-tab visibility, nested restoration and controls pass across three launches. |
| External startup links and `--space` container selection | Tab Router's native matcher and container interfaces remain present. Existing external-link, redirect, POST and cross-container routing cases pass. The OS-level cold-start command-line path was source-reviewed, not driven by the runtime suite. |
| Sidebar re-entry now clears the native hide timeout | Retain Library's existing safeguard: it also cancels a queued `_removeHoverFrames` animation frame, which the new native enter handler does not cancel. |
| Library download clicks and progress styling | Existing pop-out actions, history rows and icon styling pass. No mod overrides the changed full-Library row-click implementation. |
| Boosts focus/zap UI | No mod depends on the removed zap controls or stylesheet selectors. |

## Repository change

`tools/zen-smoke.py --library-hover --arc ../Arc-2.0` failed before browser checks with `ValueError: relative path can't be expressed as a file URI`. Resolve the stylesheet path before converting to a URI, matching the other runtime suites. One executable line changed; no dependency added.

## Feature adoption

- **Glassflow 3.70.0:** the new native Boosts Zap bar uses the shared overlay fill and blur. Its setting offers Off, Blur and Darkened. Light/dark text follows the fill; reduced transparency uses an opaque surface. Zen retains the shadow buttons, localization, focus rings, actor messages and page-space reservation. No observer, polling, injected shadow tree or replacement toolbar.
- **Mediaflow 2.6.3:** expanded-bar measurement now reads `gZenMediaController.frontCard.element`. The old DOM selector could select an earlier hidden card and measure zero height while another card was visible. The native getter selects the newest visible card across the multi-card stack. Existing guards for hovering, removal and hide animations remain. The Zenslop forwarding manifest matches Mediaflow.

| Release addition or fix | Use in this repository |
|---|---|
| Boosts Focus | Use the native Boost editor's Focus control to isolate a selected page region. Zen stores focus selectors separately from Zap selectors; clicking Focus again clears matching focused regions. No competing page-rewrite engine or automatic changes to saved Boosts. |
| Chrome Zap toolbar | Glassflow styles the native host; Zen keeps page content above it instead of an overlapping mod panel. |
| Per-window system media controller and multiple WebRTC cards | Mediaflow now uses native front-card selection for sizing; retains native per-window ownership and card lifecycle. Its bounded missing-audio-card retry remains necessary because the native active-controller timing check still exists. |
| Startup external routing and `--space` | Reuse native early workspace/container selection. Retain Router's initial-request handling for inherited-container links, redirects and POST exclusions; the startup fix does not replace those paths. |
| Sidebar re-entry and fullscreen scroll restoration | Receive the native fixes without a competing scroll or fullscreen implementation. Retain only existing behavior; Library's animation-frame cancellation is not replaced by clearing a timeout. |
| Glance devtools and overlay-button animation changes | Keep native Glance controls and animation ownership; no mod imports the replaced template fragment. |
| Windows CSIR PGO and other build optimizations | Benefit through the browser binary. No Zen Turbo preference can enable compiler PGO, and no unmeasured speed claim is made. |
| Firefox 158.0.1 certificate, printing, drag/drop and Linux monitor fixes | Supplied by the browser update. No certificate, accessibility, printing or window-placement overrides added. |

The updates require no settings migration. Set Boosts Zap toolbar to Off to restore its native appearance. To revert the Mediaflow change, restore its prior source and publish with a fresh version and timestamp under the repository release rules.
