# Zenslop has moved

This mod is now **[Mediaflow](../mediaflow/)**, which also takes over Better
Music Bar's options.

This folder holds only a copy of Mediaflow's `theme.json`. Sine reads it when
an install of this repository's Zenslop checks for updates, and follows its
`homepage` to `mediaflow`, so those installs become Mediaflow by themselves.
New installs should use the `mediaflow` folder.
